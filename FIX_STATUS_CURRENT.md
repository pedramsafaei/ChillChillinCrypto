### Why This Approach

The package-lock.json file requires:
- Resolved URLs for each package
- SHA-512 integrity hashes
- Complete dependency trees
- Peer dependency resolution

These can ONLY be properly generated by `npm install`. Manual editing or scripts cannot:
- Calculate cryptographic integrity hashes
- Resolve version conflicts
- Determine transitive dependencies
- Download and verify packages
